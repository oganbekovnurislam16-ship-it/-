# Jadoo — Sky edition

Modern blue travel landing page built with React, TypeScript, Vite and Tailwind CSS 4.

## Run

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Sky edition replaces the original Figma styling with a fluid blue design, a generated airplane-and-clouds background, updated typography, rounded cards and responsive navigation. Original destination photos and supporting icons remain local in `public/assets`. The generated hero is `public/assets/sky-hero.png`.

Mobile menu, navigation, testimonial controls, save-trip toggle and local form validation are interactive. Subscription is a preview and does not send or store data. Booking and authentication services are not connected. Fonts load from Google Fonts.
